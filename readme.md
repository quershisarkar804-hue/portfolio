# Abdullah Portfolio - Shoes By Abdullah's

A modern, fully responsive personal portfolio website with an integrated
mini shoe shop. Built with HTML, CSS, Tailwind CSS and JavaScript.

**Author:** Abdullah
**Location:** Multan, Pakistan
**Live Demo:** Open `index.html` in browser

---

## 🚀 Features

### Portfolio Section
- Hero section with animated profile image and floating cards
- Typing effect - Web Developer, Frontend Developer, UI Designer, Freelancer
- About, Skills with animated skill bars
- Projects with Category Filter (All / Web / UI / Shop)
- Counter animation - Projects, Clients, Experience
- Contact form with validation

### Shop Section - Shoes By Abdullah's
- Product cards with discount badges
- Size selector (38 - 44)
- Add to Cart with live cart counter
- Buy Now - Order placed alert

### Extra Effects
- Dark Mode Toggle
- Pause / Play Background Animation
- Particles Animation (90 particles)
- Cursor Glow Effect
- Animated Gradient Background
- Scrolling Marquee
- Scroll To Top Button
- Mobile Hamburger Menu

## 🧠 JavaScript Functions

| Function | Kaam |
| --- | --- |
| `toggleDark()` | Dark Mode On / Off |
| `togglePause()` | Background Animation Pause / Play |
| `toggleMenu()` | Mobile Navbar Open / Close |
| `filterProjects(cat)` | Projects Filter |
| `type()` | Typing Effect |
| `addCart()` / `buyNow()` | Shop Cart Logic |
| `selectSize(btn)` | Shoe Size Select |
| `sendMsg(e)` | Contact Form Submit |
| `scrollToTop()` | Top pe scroll |
| `downloadCV()` | Resume Download (Demo) |
